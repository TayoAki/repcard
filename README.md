# RepCard 🏋️⚾

**Every athlete gets a card.** RepCard is a native workout tracker where your training
history becomes a baseball-card-style Player Card — an Overall rating (40–99) computed
from your real consistency, volume, variety, and PRs — that you can share as an image
or a public URL.

Built from scratch with Expo (full-stack: native app + API routes in one project).
